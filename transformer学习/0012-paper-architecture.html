先看两条主干

编码器：读完整输入

输入 ID → token embedding + positional encoding → N 个 encoder layer → 连续表示 z。每层含多头自注意力和逐位置 FFN。

解码器：逐 token 输出

右移后的目标 ID → masked self-attention → 读取编码器输出的注意力 → FFN → Linear + Softmax。

为什么解码器有三种信息流？

子层Q 来源K/V 来源能看哪里
编码器 self-attention编码器前层编码器前层全部输入位置
解码器 masked self-attention解码器前层解码器前层当前位置及过去
encoder-decoder attention解码器前子层编码器最终输出全部输入位置
判断 self / cross 的方法：不要看名字猜，直接追 Q、K、V 的来源。Q/K/V 同源是 self-attention；Q 与 K/V 异源是 cross-attention。

每个子层外围：Add & Norm

y = LayerNorm(x + Sublayer(x))

这是论文原始 post-norm 顺序。x 与 Sublayer(x) 必须同形状，例如都为 [B,T,512]。残差让信息和梯度能绕过子层；LayerNorm 稳定每个 token 特征维上的尺度。

用一个翻译例子走一遍

  1. 输入 “I love learning” 被切成 token，编码器同时处理所有输入位置。
  2. 编码器 self-attention 让 “learning” 读取 “love”等上下文。
  3. 解码器训练输入是右移后的目标，例如 ` 我 爱`，目标是 `我 爱 学习`。
  4. masked self-attention 保证预测“学习”时不能读取未来正确答案。
  5. cross-attention 让当前中文位置读取英文编码器表示。
  6. 线性层给词表中每个候选 token 一个 logit，softmax 变成概率。

设 B=2，源序列长度 S=5，目标序列长度 T=4，dmodel=8。请写出：

  1. 编码器输出 z 的形状。
  2. 解码器 cross-attention 的 Q、K、V 序列长度。
  3. 每头 cross-attention 分数表的形状（忽略 batch 与 head）。
查看答案与解释

z 是 [2,5,8]。Q 长度为目标 T=4；K/V 长度为源 S=5。单头分数表是 [4,5]：4 个目标 query 分别与 5 个源 key 比较。
